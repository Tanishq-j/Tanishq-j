## ⚡ Engineering Philosophy & Focus Areas

Rather than just building standard web applications, I focus on the architecture of **intelligence and automation**. My core engineering pillars include:

* 🤖 **Agentic Workflows & Cost Optimization:** I design systems that act as intelligent gateways, using advanced LLMs (like Gemini 3.0) to parse multimodal data (PDFs, images, Excel). I prioritize optimizing API latency and costs by implementing multi-tier routing and classification logic before execution.

* 🕷️ **Resilient Data Engineering:** I build dynamic, scalable pipelines capable of high-volume web scraping and data enrichment. I have hands-on experience managing proxy networks, rate-limiting, and header masking to ensure uninterrupted data flow, coupled with real-time persistence layers like Firestore.

* 🏗️ **Containerized Full-Stack Orchestration:** I bridge complex AI logic with user-facing platforms. Whether it's spinning up a high-performance FastAPI container in Docker or building a comprehensive React Native/MERN stack application, I ensure the infrastructure scales alongside the intelligence.
